What this model represents

This is a bounded educational 16-bit simulation of selected x86 encodings, not a complete emulator or native CPU. It starts from a deterministic state: general and segment registers and flags are zero, IP is 7C00, SP is 7C00. This is not a BIOS register snapshot. Bit 1 of FLAGS is fixed to 1; undefined AF is shown as ? and encoded as 0 in the displayed word.

The model has 1 MiB of memory and a 4,096-step budget per reset. Physical addresses use ((segment << 4) + offset) & FFFFF: A20 is masked. Register offsets wrap to 16 bits; word accesses beginning at offset FFFF stop because crossing a segment limit is outside this subset. There is no interrupt delivery, BIOS implementation, timing model or device emulation; only explicitly supported teletype and serial behavior. Unsupported instructions stop with an explanation. The listing decodes sequentially; a branch can skip bytes or land at a different boundary.

Keyboard: S steps; Space runs or pauses; R resets. Shortcuts are inactive while editing a form field. Every control also works with Tab and Enter.
