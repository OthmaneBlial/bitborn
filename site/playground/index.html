THREE SMALL EXPERIMENTS

Change a destination.
Change a value.

01

AX becomes CX

Keep MOV AX, 42 selected. Flip bit 0 in the first byte, the rightmost bit. B8 becomes B9; the low opcode bits now select CX.

Simulate and find CX = 002A. The immediate bytes did not change.

02

42 becomes 43

Reset bits and CPU state. Flip bit 0 in the second byte: 2A becomes 2B. The following high byte remains 00.

Little-endian 2B 00 is 0x002B, decimal 43. AX receives the new value.

03

Flags remember a comparison

Reset, simulate MOV AX, 42, then select and simulate CMP AX, 42. AX stays at 42; ZF becomes 1 because the values are equal.

Selecting a new encoding preserves CPU state. “Reset CPU state” starts a fresh experiment.

The bytes lead. The mnemonic follows.

The displayed instruction name is a decoding of the edited bytes, never input to an assembler. Instruction meaning depends on execution mode. This playground uses a supported subset of 16-bit x86, and an unsupported encoding stops the model.
